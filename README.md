## Featured Projects

### 1. [fazaa](https://github.com/alwaleed-abu-taleb/fazaa)
**Community Volunteering Platform (Next.js 15, TypeScript, Prisma, PostgreSQL & Auth.js v5)**
- Full-stack volunteering platform built with **Next.js 15** (App Router & Server Actions), **TypeScript**, **Prisma**, **PostgreSQL (Supabase)**, and **Auth.js v5**.
- Implements atomic `SELECT ... FOR UPDATE` row-locked task claims, 3-layer RBAC, organizer verification workflows, live slot updates, and CSV/Excel roster exports.
- **Stack:** TypeScript, Next.js 15, React 19, Tailwind CSS, Prisma, PostgreSQL, Supabase, Auth.js v5

### 2. [ros2-vision-guided-control](https://github.com/alwaleed-abu-taleb/ros2-vision-guided-control)
**ROS 2 + OpenCV Real-Time Object Tracking & ESP32 Pan/Tilt Servo Controller**
- Real-time object tracking pipeline built with **ROS 2** and **OpenCV**, connected over serial to an **ESP32** pan/tilt servo controller written in C++ with **PlatformIO**.
- Covered by **73 `pytest` unit tests** with a passing **GitHub Actions** CI workflow.
- **Stack:** Python, C++, ROS 2, OpenCV, ESP32, PlatformIO, pytest, GitHub Actions

### 3. [Mario-Style-Pixe](https://github.com/alwaleed-abu-taleb/Mario-Style-Pixe)
**PIXEL DASH — 16-Bit HTML5 Canvas Platformer & OpenCV Paper Color Scanner**
- Modular 16-bit style **HTML5 Canvas** / JavaScript platformer (`PIXEL DASH`) with custom sprite rendering, audio, level data, and live character color preview.
- Paired with a Python **OpenCV / Pillow** scanner (`vision_scanner.py`) that corrects perspective on photographed paper coloring sheets and extracts user-drawn colors for in-game sprites.
- **Stack:** JavaScript, HTML5 Canvas, CSS3, Python, OpenCV, Pillow

### 4. [CPU-Simulator](https://github.com/alwaleed-abu-taleb/CPU-Simulator)
**Gate-Level 8-Bit CPU Built in Logisim-evolution**
- 8-bit CPU designed at the gate level in **Logisim-evolution**, complete with a custom ISA, hardwired control unit signals (`C0`–`C15`), and loadable RAM images.
- Includes architecture diagrams and an animated GIF demo stepping through program execution.
- **Stack:** Logisim-evolution, Digital Logic Design, Computer Architecture, Custom ISA
